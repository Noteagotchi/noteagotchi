# Graph Databases

## Neo4j

- mature ecosystem
- GDS (Graph Data Science) library - GraphSAGE out of the box
- disk-backed persistence model
- more polished and widely supported cypher dialect

## Memgraph

- Neo4j compatible
- in-memory architecture
- MAGE (Memgraph Advanced Graph Extantions)
- Lighter operationally

I think Memgraph is going to be a better option for Noteagotchi as it will be lower latency and lighter weight.
